# Security Policy

LoopKit is a set of prompts, templates, and shell scripts. Relevant security issues include:

- Installer behavior that overwrites or deletes user files unexpectedly
- Shell injection or unsafe handling of paths/arguments in scripts
- Prompt text that weakens safety guardrails (for example, removes the production-approval rule)

## Reporting

Please do **not** open a public issue. Use GitHub's "Report a vulnerability" (private advisory) on this repository,
or email `<dhruvnarayan1023@gmail.com>`. We aim to acknowledge within 5 business days.
